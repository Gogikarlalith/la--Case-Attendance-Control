# La Casa Attendance Control

A Money Heist-inspired attendance dashboard built with HTML, CSS, and JavaScript. It provides a polished biometric check-in experience for recording entry and exit attendance.

## Features

- Face-verification style camera interface
- Separate **Mark Entry** and **Mark Exit** actions
- Attendance log with operative name, date, entry time, exit time, and status
- On-site, present, pending, and average-arrival dashboard summaries
- Searchable attendance records
- One-click CSV export of the attendance log
- Dark and light display modes
- Responsive layout for desktop and mobile

## Run locally

1. Download or clone this repository.
2. Open `index.html` in any modern browser.
3. Enter an operative name and select **Mark Entry** or **Mark Exit**.

> The camera interface is a front-end prototype. A real facial-recognition system needs a secure backend, user consent, and compliant biometric-data storage.

## Project files

```text
index.html  # Page structure
style.css   # Money Heist visual design and responsive styles
app.js      # Attendance actions, logs, search, theme, and CSV export
```

## Publish with GitHub Pages

1. Upload `index.html`, `style.css`, `app.js`, and this `README.md` to the repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then click **Save**.
5. GitHub will show the live website link after deployment.

## Theme

The interface uses a red, black, and white control-room aesthetic inspired by *Money Heist*.
